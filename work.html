Work · 01 — Agentic AI

Federated search across every Salesforce org, from one prompt.

Most enterprises that have grown by acquisition end up with several Salesforce instances instead of one — separate orgs for different regions or business units, each with its own data. I connected Claude to every org at once through the Model Context Protocol: a custom MCP connector authenticates against each org's API, and when a user asks a question, Claude fires the same SOSL/SOQL search against all instances in parallel, then merges, de-duplicates, and ranks the combined result set before answering. What used to mean logging into four separate orgs and searching each one by hand becomes a single conversational query.

Work · 02 — Applied AI

Enterprise document search, fully self-hosted.

Some organizations can't — or won't — send internal documents to a public cloud AI service. This stack proves you don't need to: it runs entirely on infrastructure you control, with no dependency on AWS, Azure, or GCP. A Java ingestion service parses and chunks internal documents (PDFs, Word files, wikis, Confluence exports); a self-hosted Llama model turns each chunk into an embedding; and a self-hosted vector database stores those embeddings for similarity search. At query time, the same Java service embeds the user's question through the same model and asks the vector store for the nearest matches — sensitive data never leaves the firewall.
